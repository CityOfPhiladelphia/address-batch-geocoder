# Address Batch Geocoder
The **Address Batch Geocoder** lets users standardize and geocode a list of addresses, enabling that list to be used for mapping, spatial analysis, and integration within the City of Philadelphia's geospatial data ecosystem. 

It also allows users to specify a list of optional enrichment fields to be returned, providing them with publicly available data about the address. There are over 80 optional fields to choose from.

## Why use the Address Batch Geocoder?
* **:lucide-chart-no-axes-combined: Maximize Coverage:** The geocoder is designed to find a match for as many addresses as possible. If an address doesn't match to the local address database, the geocoder tries up to two additional sources.
* **:lucide-hard-drive: Run Locally:** The geocoder runs from your computer. No data is uploaded to a remote server.
* **:lucide-pause: Quit and Resume:** Got a big file that takes a long time to geocode? You can stop and resume geocoding later.
* **:lucide-panels-top-left: Graphical Interface:** The geocoder can launch as a local app in your web browser, no coding knowledge required.
